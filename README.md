## 计网

前面的喷完了，说点感兴趣的。

今天一口气把 cs144 的整个 TCP 写完了，后面关于以太网的部分还没写，也看了下如何把内核的 TCP 换掉（看的不太懂，我是 cpp 低手）。

简单来说，作业要求实现的东西不多：

- 一个 io 数据流存储。
- 一个 32bit-64bit 转换器。
- tcpsender，用于发包，SYN, FIN 那些也能发。
- tcpreceive，支持乱序收包。

lab 代码几乎完成了全部的 tcp 组装工作，于是花了点时间看这玩意怎么组装起来的，下面说的不全，因为我只看了一点点（好难啊实在看不下去）：

显然的问题是如何把 os 层的 tcp 给换掉，换内核肯定成不了，我们用到了 tun，tun/tap 是虚拟网卡，前者处理 ip 层后者处理以太网，因此我们用实验代码给的魔法脚本就开启了一个 tun（后面会看咋申请的）并桥接，这是一个 fd，这个 fd 直接能写报文收报文，且是由软件控制的，因此借助这个 tun，我们就能绕过 os，把自己的 tco 给接上去。

显然我说的很笼统了，因为我代码屁都看不懂（）。

## ACM

显的没事打一打 ACM，结果上来一道题就不会做（）。

![img](https://img2024.cnblogs.com/blog/3585830/202610/3585830-20261005211906226-1139315754.png)

总的来说，这题上来一个想不到的转化，然后就范德蒙德卷积加生成函数了（？？？这是第一题啊）：

$$
\begin{aligned}
\sum_{0\le a<b} \binom{s}{b}\binom{N-s}{a}(b-a)
&= \sum_{c\ge 1}\sum_{a\ge 0} \binom{s}{a+c}\binom{N-s}{a}c \\
&= \sum_{c\ge 1} c \sum_{a\ge 0} \binom{s}{s-a-c}\binom{N-s}{a} \\
&= \sum_{c\ge 1} c \binom{N}{s-c} \\
&= \sum_{d=0}^{s} (s-d)\binom{N}{d} \\
&= [x^s] \frac{x(1+x)^N}{(1-x)^2}
\end{aligned}
$$

在 gemini 大人的悉心教学下也是写出来了，顺便复习了一下之前看不懂的生成函数。
